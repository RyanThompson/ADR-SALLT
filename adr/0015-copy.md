# 0015 Copy and Translation

**Status:** Accepted · **Layer:** Laravel · **Principles:** P2 · **Stack:** 0001

> Every user-facing word is a translation key in its domain's vocabulary.

## Rules
1. No hard-coded user-facing strings: labels, headings, placeholders, hints, buttons, empty states, notifications, validation.
2. Keys live in `lang/{locale}/domains/{domain}.php`, nested by screen → component → field/action.
3. PHP lang files use nested arrays, never flat dotted keys.
4. Locales are `en`, `es`, `pt_BR`. Every locale keeps the default locale's key structure.
5. A word with domain meaning never uses a generic `common.*` key. *(warning)*

## Shape
```php
// lang/en/domains/todos.php
return [
    'settings' => [
        'profile' => [
            'heading' => 'Profile',
            'actions' => ['save_name' => 'Save name'],
        ],
    ],
];

__('domains/todos.settings.profile.actions.save_name');
```

## Not
- `->label('Archive todo')`.
- Copy-as-key (`__('Save todo')`).
