# 000.3 Foundations

**Status:** Accepted

Every ADR applies these nine principles. They hold in any stack and apply **before** architecture. Stack reach order and platform law live only in [`adr/0001`](adr/0001-salty-stack.md). An ADR that contradicts these principles is wrong — fix the ADR. An ADR that restates the stack instead of citing 0001 is wrong — cite 0001.

## Principles

### P1 One Owner
> Every fact has exactly one owner. Only the owner changes it. Everyone else asks or listens.

Two writers means no one is accountable, and the bug lives in the seam between them.

- [ ] Every value this change writes has one named owning domain.
- [ ] Every write originates inside its owner.
- [ ] Non-owners reach it only by calling the owner's public capability (now) or reacting to its event (later).
- [ ] Listeners, imports, reports and addons get no back door.

*Applied in:* 0009, 0012, 0013, 0014, 0006, 0017

### P2 Names Carry Intent
> A name says what a thing does or what happened. Commands are imperative. Facts are past tense. Containers say what they hold.

Code is read far more than written, by people and agents. A precise name is the cheapest documentation and the first review.

- [ ] Commands are specific Verb+Noun (`CompleteTodo`), never `Process`, `Handle`, `Manage`, `Save`.
- [ ] Facts are Subject+PastVerb (`TodoCompleted`), never `Was`/`Were`.
- [ ] Types carry their role suffix: `*Data`, `*Form`, `*Table`, `*Modal`, `*Card`, `*ApiResource`, `*Policy`, `*Result`.
- [ ] Domains are business nouns, never technical buckets (`Helpers`, `Managers`, `Data`).
- [ ] One concept, one word — the same in code, copy, translation keys and API.

*Applied in:* 0009, 0010, 0011, 0012, 0015, 0003, 0021

### P3 Context Is Explicit
> Who, where and when are resolved once, at the edge, and passed down. The core never reaches for ambient state.

Code that reads globals behaves differently in a request, a queue and a test. Explicit context makes behavior replayable.

- [ ] Edges are: HTTP endpoint, Livewire host and its UI builders, console command, scheduler. Listeners and jobs are not edges — they take context from the event or job payload.
- [ ] Actor, tenant, time and source travel in the DTO.
- [ ] No `auth()`, `request()`, `session()`, `now()` below the edge.
- [ ] Each surface has one tenant resolver (`UI::getTenant()`, `API::getTenant()`); tenant never comes from user input.
- [ ] The same code, replayed from a queue at 3 a.m., produces the same result.

*Applied in:* 0010, 0011, 0014, 0019, 0020, 0004, 0006

### P4 Fail Loud
> Required means required. Optional is declared, never assumed. A broken invariant is an error, not a default.

A silent fallback turns a bug you would see today into corrupt data you find next quarter.

- [ ] Every `??`, `?:`, `?->`, `optional()` or default maps to a field declared optional.
- [ ] Required state is read directly or guarded by a named exception.
- [ ] If removing a fallback breaks something, the contract upstream is broken — fix it there.
- [ ] Data is normalized at the boundary, never coerced (`{}` silently becoming `[]`).

*Applied in:* 0011, 0016, 0018

### P5 Facts Are Canon
> Record what happened once, in its owner. Everything computed from facts is disposable: it can be deleted, rebuilt, and never writes back.

One source of truth cannot disagree with itself. Derived data that writes back creates a second truth.

- [ ] New storage is classified: fact or derivation.
- [ ] If an existing fact already answers the question (a timestamp, a row), add no storage.
- [ ] Every derivation can be dropped and recomputed.
- [ ] No derivation writes canonical state.
- [ ] Where history cannot be rebuilt, the owner records it — or the limit is documented.

*Applied in:* 0009, 0013, 0017

### P6 Register, Don't Discover
> Everything that runs is declared at a known boot point. Register, then resolve. No scanning, no renamed defaults.

If you can't grep for where a thing is wired, no one can reason about whether it runs.

- [ ] Every resource, endpoint, policy, form, action, addon, calculator and client component is registered in a provider, `boot()`/`setUp()`, or one JS entry file.
- [ ] The owner registers; the owner resolves; registration comes first.
- [ ] Framework-derived names are kept (no `getDefaultName()`/`statePath()` overrides); a different name is passed explicitly at the call site.
- [ ] One grep finds the registration.

*Applied in:* 0014, 0020, 0004, 0021, 0008, 0006, 0007, 0017

### P7 Compose at the Top, Own at the Bottom
> Each concern has one home. Composers wire; owners do. Pages, endpoints and listeners stay thin.

When a page also validates, queries and saves, every change to it is a change to everything.

- [ ] You can point to the single class that owns this concern.
- [ ] The composer (page, endpoint, listener) reads like a table of contents.
- [ ] Every write follows one path: validated input → DTO → dispatched action → event.
- [ ] No abstraction is rebuilt inline where a dedicated one exists.

*Applied in:* 0010, 0019, 0003, 0020, 0004, 0021, 0006

### P8 Fix the Source
> Repair the broken thing where it lives. Never fork what you depend on. Never invent what a standard already defines.

A local patch fixes one screen and forks the platform; the next upgrade breaks it silently.

- [ ] A package bug is fixed in the package and upstreamed, never shadowed in the app.
- [ ] A capability the package provides is used, not reimplemented.
- [ ] Where a public standard exists (Standard Webhooks, PSR, native HTML), it is followed exactly.
- [ ] An existing pattern in the codebase is mirrored before a new one is invented.

*Applied in:* 0008, 0022, 0002, 0016, 0006, 0018

### P9 Nothing Without a Job
> Every class, wrapper, field, icon and word does work nothing else already does. If it can be removed with no loss, remove it.

Every addition is read, maintained and paid for forever. Only work earns that cost.

- [ ] A new abstraction has domain meaning, real reuse, or removes real complexity — otherwise it stays local.
- [ ] A wrapper adds behavior beyond pass-through (no `Card` just to title a `Table`).
- [ ] An icon carries meaning its label does not.
- [ ] A description says something the page does not.
- [ ] New storage answers something existing data cannot.

*Applied in:* 0019, 0003, 0004, 0022, 0005, 0017
